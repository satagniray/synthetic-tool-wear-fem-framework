# IP and data disclaimer

This repository is an independently developed portfolio demonstrator inspired
by publicly available literature on FEM-based tool-wear prediction. It is not
an official RWTH Aachen University or MTI repository. It contains no
confidential institute, partner-company, unpublished research, or proprietary
project data/code. All geometry, process inputs, datasets, and example outputs
are synthetic or independently generated for demonstration purposes.

## How the repository was built

It is a **clean-room implementation**, written specifically for this public
repository from:

1. public scientific literature (in particular Xie et al., *Wear* 258 (2005)
   1479–1490, and the Usui-type wear law it uses);
2. generic engineering and numerical-methods knowledge;
3. synthetic data generated by the code in this repository.

## What the repository does **not** contain

* source code, scripts, input decks or result files from any institute
  repository or research project;
* real tool or workpiece geometry, real cutting conditions, material or
  calibration constants from unpublished work;
* measurements, internal test results, internal paths, server names,
  screenshots, reports, correspondence or thesis text;
* any solver input deck (`*.inp`) or result database (`*.odb`) - these file
  types are excluded by `.gitignore`.

The optional solver backend (`backends/abaqus_stub.py`) is intentionally a
documented stub; it raises `NotImplementedError`.

## Relation to academic work

The author's master's thesis is a separate piece of academic work. This public
demonstrator shows the same *class* of engineering competence (automated,
multi-cycle wear simulation) using independent code and synthetic data; it is
not the thesis codebase and makes no claims about the thesis results.

This statement is not legal advice.
