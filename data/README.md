# Data

Everything in this folder is **generated by code** in this repository and is
**synthetic**. No measurement, simulation result, geometry or material value
from any institute, company or unpublished research project is included.

| Path | Content | How to regenerate |
|---|---|---|
| `synthetic/example_process_fields.csv` | Synthetic contact pressure, interface temperature, sliding velocity and the resulting wear rate on the 77 wear-surface nodes of the unworn default tool (cycle 1) | `python -m tool_wear_demo.cli generate-demo-data` |
| `synthetic/example_process_fields.meta.yaml` | Provenance metadata (source, seed, units, purpose) | same command |

Simulation runs are written to `results/` (git-ignored) and can always be
reproduced from the configuration files in `config/` because every run is
seeded.
